# Checkpoint QR Files

These are generated ID codes, not surveyed 3D anchors. They are not the old QR decorations baked into the GLB. The IDs correspond to `UnityProject/Assets/Campus/Data/campus.json`.

Before installation, get campus permission, measure floor heights and standing-point positions, add a physical standing mark and heading arrow, and verify the printed code scans at the intended distance and light. The existing `surveyed: false` flags deliberately prevent these provisional locations from authorizing real navigation.

Use a clear white quiet border; do not stretch the QR or place it across a corner. Include a human-readable building/floor/checkpoint name on the physical sign. Record each marker's location and a photograph in the survey record. A code can be copied or moved, so it is not authentication or proof of physical location.
